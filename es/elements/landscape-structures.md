# Estructuras del paisaje

Estructuras exteriores iluminadas, como estructuras de sombra, pérgolas, cenadores, enrejados, quioscos, mamparas y elementos paisajísticos personalizados.

![Estructuras del paisaje](https://www.desertscapeco.com/assets/visual-landscape-structures-premium-riyadh.jpg)

## Alcance del elemento.

- Estructuras de sombra, pérgolas, enrejados, quioscos, mamparas y alcance de funciones personalizadas
- Coordinación de materiales, acabados, anclajes, drenaje, iluminación y interfaz paisajística.
- Planificación de suministro, fabricación, instalación, inspección y entrega.
- Acceso para mantenimiento, revisión de durabilidad y planificación de mejoras para estructuras exteriores

Este elemento puede entregarse como un suministro independiente, instalación, actualización o mantenimiento, o como parte de un paquete completo de diseño, suministro, construcción, operación y mantenimiento.
